# Risk-Aware Smart Navigation System

## Project Overview
Risk-Aware Smart Navigation System is a web-based navigation platform that helps users identify both the shortest and safest routes. The system integrates accident-prone zone detection, weather conditions, traffic information, and route optimization techniques to improve road safety.

## Problem Statement
Traditional navigation systems focus mainly on shortest distance and travel time while ignoring safety-related factors such as accident-prone locations, weather conditions, and traffic risks.

## Objectives
- Identify accident-prone zones.
- Generate safer travel routes.
- Calculate Estimated Time of Arrival (ETA).
- Monitor traffic and weather conditions.
- Provide emergency navigation assistance.

## Technologies Used

- CSS3
- JavaScript
- TomTom Maps SDK

## Features
- Shortest Path Navigation
